## ☁️ Module 1 – Introduction to Cloud
### What is Cloud Computing?
Cloud computing is basically "Delivering on demand IT resources over the internet on pay-as-you-go pricing"
### AWS Global Infrastructure
[1]It consist physical locations around the world that contains group of        data structures .
[2]These group of  data structres are called Availability Zones (AZs).
### Concept of Availability Zones
AZs consist of one or more data centers inside it with redundant power , networking and connectivity . Regions and availability zones are designed to proved to be low latency ,fault-tolerant access to services for users within a given area . 
### Shared Responsibility Model
[1] CUSTOMER RESPONSIBILITY( Security IN cloud) :
(a) Customer data 
(b) Client side data encryption 
[2] Customer or AWS responsibility (varies by service):
(a) server side encryption
(b) network traffic operation, performance and application management            OS,network,firewall configuration.
[3] AWS Responsibility ( Security OF cloud) :
(a) software for compute storage.
( b) database and networking 
(c) hardware and AWS global infrastructure.

## ☁️ Module 3 – Exploring Compute Services 
This module gave me a practical understanding of AWS compute services, so we  can choose the right tools for your applications. I  learned when to use fully managed options like Lambda or Fargate, and when full control with Amazon EC2 made sense.  Explored how containers solve deployment consistency issues and how AWS services, like Amazon ECS and Amazon EKS, simplify managing and scaling containerized applications , also discovered services like Elastic Beanstalk, AWS Batch, Lightsail, and Outposts, and how each supported specific use cases, from basic web hosting to large-scale batch processing or hybrid cloud environments.
